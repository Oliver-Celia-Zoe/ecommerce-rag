# 智能空气炸锅 Pro 产品说明书

## 产品概述

智能空气炸锅 Pro 是一款家用厨房电器，采用高速热风循环技术，无需加油即可烹饪出酥脆美味的食物。相比传统油炸，可减少高达 80% 的油脂摄入。

## 规格参数

| 项目 | 参数 |
|------|------|
| 容量 | 5.5 升（适合 3-5 人家庭） |
| 功率 | 1500W |
| 温度范围 | 80°C - 200°C |
| 定时范围 | 1-60 分钟 |
| 产品尺寸 | 35cm x 28cm x 32cm |
| 重量 | 4.2kg |
| 内胆材质 | 食品级不粘涂层 |

## 适用人群

- 3-5 口之家的日常烹饪
- 追求健康饮食、减少油脂摄入的用户
- 厨房空间有限、希望一机多用的家庭
- 烹饪新手（预设菜单简化操作）

## 核心功能

### 1. 高速热风循环
内置 1500W 大功率风扇，360° 循环热风均匀加热食物表面，形成酥脆外壳。

### 2. 8 大预设菜单
- 薯条（200°C，18 分钟）
- 炸鸡（190°C，22 分钟）
- 烤鱼（180°C，15 分钟）
- 烤红薯（200°C，35 分钟）
- 蛋挞（180°C，12 分钟）
- 牛排（200°C，10 分钟）
- 披萨（190°C，8 分钟）
- 蔬菜（160°C，10 分钟）

### 3. 智能触控面板
LED 数字显示屏，触控操作，支持温度和时间自由调节。

### 4. 安全保护
- 过热自动断电
- 抽拉式炸篮取出即停
- 防烫外壳设计
- 防滑底座
