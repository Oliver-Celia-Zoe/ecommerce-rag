# 售后常见问题解答（FAQ）

## 使用问题

### Q1: 第一次使用需要做什么？

首次使用前，请按以下步骤操作：
1. 取出炸篮和烤盘，用温水中性洗涤剂清洗并擦干
2. 将空炸锅以 200°C 运行 10-15 分钟，去除新机的保护油层
3. 运行期间可能有轻微异味，属于正常现象
4. 冷却后再次清洗炸篮即可开始使用

### Q2: 炸篮放入食材后推不进去怎么办？

请检查以下几点：
- 食材不要超过炸篮最大容量线（约 5.5 升）
- 确保炸篮底部没有异物卡住
- 炸篮需要水平推入，不要倾斜
- 如仍无法推入，请联系售后

### Q3: 烹饪中途可以打开炸篮查看吗？

可以。本产品采用抽拉式炸篮设计，取出炸篮时加热自动暂停，推回后继续之前的程序，无需重新设置。

### Q4: 为什么食物表面不够酥脆？

可能原因及解决方法：
- **食材过多**：热风无法循环，请分批烹饪或减少食材量
- **水分过多**：食材表面水分太多，建议用厨房纸吸干
- **温度过低**：适当调高 10-20°C
- **时间不足**：延长 3-5 分钟
- **未翻面**：烹饪到一半时翻面，确保两面均匀受热

### Q5: 烹饪时冒烟正常吗？

少量白烟属于正常现象，是食材水分蒸发。但如果出现大量浓烟，请立即停止使用并检查：
- 食材油脂含量是否过高（如五花肉）
- 炸篮底部是否有食物残渣或油渍积累
- 温度设置是否过高

## 故障排除

### 故障1: 空气炸锅不加热

**现象**：通电后风扇运转，但温度不上升。

**排查步骤**：
1. 确认温度已设置（不低于 80°C）
2. 确认定时器已设置（不低于 1 分钟）
3. 检查炸篮是否正确放入（未放入时安全开关不启动加热）
4. 拔掉电源等待 5 分钟后重新插电

如以上步骤无效，可能是加热管故障，请联系售后维修。

### 故障2: 显示屏不亮

**现象**：插电后无任何显示。

**排查步骤**：
1. 检查插座是否有电（换其他电器测试）
2. 检查电源线是否插紧
3. 检查家中是否跳闸
4. 如以上均正常，可能是主板故障

### 故障3: 风扇噪音过大

**现象**：运行时发出异常响声。

**排查步骤**：
1. 检查炸篮内是否有异物（如锡纸碎片、骨头等）
2. 检查风扇格栅是否有食物残渣堵塞
3. 关机冷却后，用软毛刷清理风扇区域

如清理后仍有异响，可能是风扇轴承磨损，需联系售后。

## 清洁保养

### 日常清洁
- 每次使用后，待完全冷却再清洗
- 炸篮和烤盘可用洗碗机清洗（上层架）
- 主机外壳用湿布擦拭，不可浸入水中

### 深度清洁（建议每月一次）
- 取下炸篮底部的橡胶垫，清洗缝隙
- 用软毛刷清理加热管区域的油渍
- 检查风扇格栅是否有积油
